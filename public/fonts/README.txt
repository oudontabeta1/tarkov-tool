Bender フォントの置き場所
=========================

1. https://www.cufonfonts.com/font/bender からフォントをダウンロードして展開します
   (ライセンスは配布ページで確認してください。このアプリには同梱していません)
2. 次のファイル名のいずれかで、このフォルダに置きます
     Bender.ttf  /  Bender.otf  /  Bender.woff2        (通常の太さ)
     Bender-Regular.ttf / .otf / .woff2                (同上)
     Bender-Bold.ttf / .otf / .woff2                   (太字。無ければ通常の太さを使います)
3. アプリを再起動します(npm run tauri dev を再実行)

PCにBenderをインストール済みの場合は、ファイルを置かなくても使われます。
Benderに無い文字(日本語など)は、自動的にシステムのフォントで表示されます。
